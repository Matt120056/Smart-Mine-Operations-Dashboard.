================================================================
SMART MINE OPERATIONS DASHBOARD
Storyboard / Wireframe Walkthrough
================================================================

PURPOSE
-------
A simple two-page prototype for a mine monitoring and safety
dashboard. It shows equipment, sensors and warnings at a glance
so an operator can quickly see what is happening on site.

FILES
-----
  index.html   -> Dashboard page
  sensors.html -> Sensors page
  styles.css   -> Shared styling for both pages

COLOURS
-------
  Dark blue   (top bar)       #1f2d3d
  Light grey  (page bg)       #f2f5f9
  White       (cards)         #ffffff
  Green       (online tag)    #16845b
  Orange      (warning tag)   #a96b08

================================================================
MOBILE / NARROW SCREEN BEHAVIOUR
================================================================

  - Below 700px wide, the sidebar moves ABOVE the main content
    (stacked layout instead of side-by-side).
  - Sidebar links display inline (in a row) instead of
    one per line.
  - Cards in each row stack vertically.
  - Top bar wraps to two lines if needed.

  Layout change:

    DESKTOP                      MOBILE
    +--------+----------+        +-------------------+
    |        |          |        |     TOP BAR       |
    | SIDE   |   MAIN   |        +-------------------+
    | BAR    |          |        |     SIDEBAR       |
    |        |          |        +-------------------+
    +--------+----------+        |     MAIN          |
                                 +-------------------+
