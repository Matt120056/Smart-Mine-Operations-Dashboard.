# Milestone 2 starter files

Copy the contents of this folder into your existing `studio-project-1` repository. Do not replace your Milestone 1 files.

- `notebook-m2.md` goes in the root of the repository.
- `site/app.js` and `site/home.js` go next to your HTML files.
- `site/data.example.json` is a model for a different project. Do not reuse its content. Your own file is `site/data.json`.
- `screenshots/m2/` is where your Milestone 2 screenshots go.

You can delete this file after you copy the rest.
